# P2P Chat Software


- [ ] Bootstrap module for initial connection from client to one peer of the network (include an optional root dns, the user can input an IP of the network himself)
- [ ] Kademlia-like DHT system across the nodes
- [ ] Store node informations for next login (proprietary format)
- [ ] Unique User Identification through users' computer 'enthropy', using motherboard ID, cpu manufacturer ID, cpu model, GPU model, and other detected peripherals, melted with username. Each users have pub / priv key (should use modern algorithm quantum resistant) in order to validate user identity.
- [ ] Share file/folders directly peer to peer.
- [ ] CLI Interface
- [ ] GUI Interface
- [ ] Paranoia mode (anti-nmap), shared anti ddos service across network
- [ ] Administrator system
- [ ] Video + voice call
- [ ] Segmented list pour la gestion des messages
